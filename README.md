# UCC 排班系統

> 讓一群人**依順位輪流填班**的網頁，資料直接寫回你現有的 Google 試算表。
> 用 Google Apps Script 寫成，不用租主機、不用資料庫、不用付費。

這套系統源自臺中市藥師公會的實際需求：16 位藥師輪流支援醫院假日急診（UCC），
原本是共用一份 Google 試算表、大家自己去格子裡打名字。系統上線後試算表一格都沒動，
只是把「打名字」換成「點一下」，並把排班規則變成即時提示。

**線上示範**（假名、假資料、沒有後端）：<https://tccpa-ucc-demo.rph-liyang.workers.dev/>
任選使用者、密碼 `0000`。選 `Ｂ．陳○美` 可看後臺管理（超級管理者），`Ｚ．會務人員` 是不參與排班的帳號。

---

## 適合誰

- 藥師公會、護理師公會、醫事人員團體：要輪流支援假日門診、急診、疫苗站
- 任何「一群人按順位輪值、目前用試算表或 LINE 喊」的組織
- 已經有 Google 帳號，不想另外架系統、也不想每月付費的人

不適合：需要複雜排班演算法（自動排班、偏好最佳化）的場景。這套系統是**人填、程式提醒**。

## 它做什麼

| 功能 | 說明 |
|---|---|
| 一鍵填班 | 點空格就寫入自己的名字，寫回試算表同一格；點自己的班可取消，都能立即復原 |
| 順位輪替 | 「目前輪到誰」由試算表的「完成註記」決定；填完按「換下一位」交棒，每月自動整體遞補 |
| 規則即時提示 | 每月班數上限、連續天數、晚班接早班、長連假優先權、期限…不符時跳警示但**不硬擋** |
| 多人同時填 | 每 60 秒自動同步；搶同一格的後手會被擋下，資料不互相覆蓋 |
| 個人密碼登入 | 代號＋4 到 6 位數字密碼；登入頁只顯示遮罩姓名（王○明）；連錯 10 次鎖 10 分鐘 |
| 班表鎖定 | 定案後鎖定該月，所有人仍可查閱但不能改；到該月 1 號自動解除 |
| 後臺管理 | 建立次月分頁、編輯開放日、注意事項、標記逾期、重設密碼、增減人員、**頁首頁尾文字**（標題與說明文字在後臺改，不必重新部署） |
| 權限授權 | 超級管理者（預設是會務人員帳號）可把個別後臺功能開放給任何帳號 |
| 操作紀錄 | 每一筆填班、取消、交棒、後臺操作都寫進隱藏分頁 `_操作紀錄` |
| 手機優先 | 手機版是日期卡片（☀ 早班／☾ 晚班），電腦版是比照試算表的月曆 |

## 架構一張圖

```
藥師手機／電腦
     │  HTTPS
     ▼
Google Apps Script 網頁應用程式（Index.html ＋ Code.gs）
     │  SpreadsheetApp（以部署者身分讀寫）
     ▼
你現有的 Google 試算表
     ├── 115/10、115/11 …   每月一個分頁：月曆＋順位面板＋注意事項
     ├── _可排班日            週日以外哪天要開（隱藏）
     └── _操作紀錄            誰在什麼時候做了什麼（隱藏）

密碼雜湊、登入 token 的祕密、鎖定狀態、授權表 → 存在 Apps Script 的 ScriptProperties
（不放試算表：填班的人對試算表有編輯權，放進去等於沒藏）
```

沒有另建資料庫。**試算表仍是唯一的資料來源**，網頁只是好用一點的填寫介面；哪天想停用，把網址收回就好，班表還在。
細節見 [docs/architecture.md](docs/architecture.md)。

## 10 分鐘上線

完整步驟在 [docs/deploy.md](docs/deploy.md)，摘要如下：

1. 按右上角 **Use this template** 建自己的 repo（或直接下載 ZIP）。
2. 到 <https://script.google.com> 新增專案，把 `src/` 的 4 個檔案貼進去
   （`Code.gs`、`Index.html`、`appsscript.json`，以及把 `Config.example.gs` 改名為 `Config.gs`）。
   會用 clasp 的人：`cp .clasp.json.example .clasp.json`、填 Script ID、`clasp push`。
3. 打開 `Config.gs`，把組織名稱、聯絡窗口、順位名單改成你們的（標題等文字之後也能在後臺改）。
   預設的超級管理者是「會務人員」帳號，**部署後第一件事是替它改密碼**。
4. 在編輯器執行 `setupSpreadsheet`：第一次會建一份新試算表並印出 ID，填回 `Config.gs` 再執行一次，
   就會建好第一個月份分頁與隱藏分頁。（已經有試算表的組織：照 [版面契約](docs/architecture.md#試算表版面契約) 對一下格式即可，不必重建。）
5. **部署 → 新增部署作業 → 網頁應用程式**：執行身分「我」、存取權「知道連結的任何人」。把網址發給大家。
6. 照 [上線檢查清單](docs/deploy.md#上線檢查清單) 跑一遍，再公告。

## 改成你們的：只改一個檔

所有組織專屬的內容都在 `src/Config.gs`：試算表 ID、管理者、會務人員帳號、規則數字、
畫面上的每一段文字（組織名、醫院與班別時間、規則清單、聯絡方式）、國定假日。
`Code.gs` 與 `Index.html` 不含任何組織專屬字串，改版時直接整檔覆蓋即可。

哪些可以改、哪些不要碰，見 [docs/customize.md](docs/customize.md)。

## 安全性，老實說

- 程式碼裡**沒有任何祕密**：密碼只存加鹽 SHA-256 雜湊、登入 token 用 HMAC 簽章、簽章金鑰在第一次執行時隨機產生存 ScriptProperties。公開原始碼不會削弱你的部署。
- 預設密碼是共用的（`0000`）。**在大家改密碼之前，任何知道網址的人都能用任一位成員的名字登入。** 公告時務必要求立刻改密碼，並用後臺的「看誰還沒改密碼」催。
- 密碼只有 4 到 6 位數字，登入鎖定是按帳號計算（不按 IP）。這是「內部使用、網址不外流」前提下的取捨；請不要把正式網址貼到公開的地方。
- 存取權設「知道連結的任何人」是為了讓成員免登入 Google 就能用手機開。若你們有 Google Workspace，可改成網域內使用者。
- 網頁以「部署者」身分讀寫試算表，建議用組織的公用帳號部署，避免人員異動後網頁停擺。

## 已知限制

- 兩班制（早／晚）寫死；三班制要改 `parseSheet_` 與前端月曆。
- 月份分頁用民國年命名（`115/10`），程式以 `民國年＋1911` 換算。非臺灣組織要改 `decodeMonth_`／`encodeMonth_`。
- 不會自動寄信或 LINE 通知下一位；跨月的連續排班不檢查。
- 無自動排班。它的定位是把人工流程做順，不是取代人。
