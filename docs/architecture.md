# 架構說明

## 設計原則

1. **不換系統，換介面。** 使用者原本就用 Google 試算表排班，管理者習慣打開試算表看、改、列印。
   系統直接讀寫那份試算表，不另建資料庫；停用時把網址收回，班表照樣在。
2. **規則是提示，不是牆。** 排班辦法裡的規則（每月一班、不得連四天、長連假優先權…）全部寫進程式，
   但只在不符時跳警示，使用者確認後仍可送出。真實世界有代壓、協調、例外；程式硬擋只會逼人回去改試算表。
3. **唯一硬擋的是資料完整性。** 兩個人搶同一格、填到不開放的日子、鎖定期間未授權者改動，這三種後端會拒絕。
4. **組織專屬內容集中在一個檔。** `Config.gs` 以外的程式碼不含任何組織名稱、人名、聯絡方式。

## 元件

```
瀏覽器（Index.html）
  ├─ CSS：手機優先，900px 以上切電腦版
  ├─ 狀態 S：登入 token、目前月份、快取、權限
  ├─ api(fn, arg)：包裝 google.script.run 成 Promise
  ├─ checkRules()：規則檢核（軟提示）
  └─ render()：月曆／日期卡片／順位面板／後臺分項
          │ google.script.run
          ▼
Apps Script（Code.gs ＋ Config.gs）
  ├─ 帳號與登入：hashPw_／checkPw_／makeToken_／tokenName_、失敗鎖定
  ├─ 權限：PERMS／can_／requireAdmin_／setPerms
  ├─ 分頁解析：parseSheet_（唯一知道版面的地方）
  ├─ 對前端的 API：getBootstrap／getMonth／submitShift／cancelShift／setDone…
  ├─ 後臺：setLock／setSlotOpen／saveNotes／adminSkip／createNextMonth／rosterAdd／rosterRemove…
  └─ 建置：setupSpreadsheet
          │ SpreadsheetApp／PropertiesService／CacheService／LockService
          ▼
Google 試算表 ＋ ScriptProperties
```

## 資料在哪裡

| 資料 | 位置 | 為什麼 |
|---|---|---|
| 班表、順位、完成註記、注意事項 | 試算表月份分頁 | 使用者原有的東西，管理者要能直接看與改 |
| 週日以外哪天開放 | 試算表 `_可排班日`（隱藏） | 管理者要能改 |
| 操作紀錄 | 試算表 `_操作紀錄`（隱藏） | 事後查誰在什麼時候做了什麼 |
| 密碼雜湊 `pw_<姓名>` | ScriptProperties | 填班的人對試算表有編輯權，放試算表等於沒藏 |
| token 簽章金鑰 `AUTH_SECRET` | ScriptProperties | 第一次執行隨機產生 |
| 鎖定狀態 `LOCK` | ScriptProperties | 不需要排程：每次讀取時判斷是否到期 |
| 授權表 `perm_<姓名>` | ScriptProperties | 同上 |
| 頁首頁尾文字覆蓋 `UI_OVERRIDE` | ScriptProperties | 後臺改文字不必重新部署；`effectiveUi_()` 合併到 `CFG.UI` 上 |
| 登入失敗計數 `fail_<姓名>` | ScriptProperties | 暴力猜密碼防護 |
| 前三個月排班次數 `pc_<月份>` | CacheService（5 分鐘） | 要多讀三個分頁，是最慢的查詢 |

## 試算表版面契約

`parseSheet_()` 不寫死列號，靠內容定位。只要符合下面的規則，任何長相的分頁都能用。

| 項目 | 規則 |
|---|---|
| 分頁名稱 | `115/10`（民國年/月）或 `11510`；其他名稱一律略過 |
| 月曆欄位 | B～H 欄＝週日～週六 |
| 週的結構 | 連續三列：**日期列**（B～H 是 Date 物件）、**早班列**、**晚班列**。程式掃描「B～H 出現 Date」的列當週起始 |
| 格子內容 | `X`（不分大小寫）＝不開放；空白＝可填；其他文字＝已填的姓名 |
| 順位面板 | 在 I～T 欄找到值恰為「排序」的儲存格；同列右邊兩格是「姓名」「完成註記」；往下逐列讀，排序與姓名都空白就停 |
| 完成註記 | 勾選框（TRUE/FALSE）；`true` 或字串 `TRUE` 都算完成 |
| 注意事項 | 第 1～6 列、I～Y 欄找開頭為「當月班表填寫注意事項」的儲存格；其下方同欄最多 11 列是內容 |
| 不能做的事 | 順位面板與月曆共用列，**任何操作不得插入或刪除整列** |

`setupSpreadsheet()` 建出來的分頁：第 2 列星期標題、第 3 列起每週三列、A 欄班別標籤、
J～L 欄順位面板（J3「排序」）、N2「當月班表填寫注意事項：」。

## 順位機制

- 「目前輪到誰」＝順位面板由上往下**第一個完成註記未勾**的人。
- 填完（或決定不填）按「換下一位」＝把自己的完成註記勾起來。**不排班的人也要按**，否則順位卡住。
- 建立次月分頁時，順位整體左移一位（第一位移到最後）、完成註記全部清空。代號跟人走，不跟月份走。
- 新人加入放最後、代號接續；移除人員時重寫面板區塊並清掉最後一列。

## 登入與權限

- 登入頁只送「全形代號＋遮罩姓名」（`Ｂ．王○明`），完整姓名不進未登入頁面的原始碼。
- 密碼 4～6 位數字，存 `SHA-256(secret | 姓名 | 密碼)`。未設定過就比對 `DEFAULT_PASSWORD`。
- 登入成功發 HMAC-SHA256 簽章的無狀態 token（姓名｜到期時間｜簽章），存瀏覽器 localStorage，30 天。
- 每個寫入 API 都帶 token；後端用 `actorOf_()` 解出操作者，代填時紀錄寫「代填（操作者 ○○○）」。
- 連續錯 10 次鎖 10 分鐘（按帳號計）；超過 10 分鐘沒再錯就歸零。
- 權限兩層：`ADMIN_NAMES` 超級管理者全功能＋可授權；其他帳號逐項授權（9 個鍵）。前後端都檢查，前端只是顯示與否。

## 並行與效能

- 填班、取消、交棒、開關格子、增減人員都包 `LockService.getScriptLock()`，先重讀分頁再寫。
- 前端每 60 秒背景同步（分頁在背景或有確認視窗時不打擾），資料簽章沒變就不重畫。
- 月份資料前端快取；切換月份先畫快取再更新，並預抓前後各一個月。
- Apps Script 對已部署頁面有快取，改版後驗證要加 `?cb=`。

## 沒做的事（刻意）

- 不自動開放國定假日：哪天開診是醫院與管理者的決定，程式不猜。週日自動開，其餘要在 `_可排班日` 標「是」。
- 不自動排班、不通知、不做跨月連續檢查。
